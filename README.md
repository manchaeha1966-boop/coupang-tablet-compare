# 쿠팡 태블릿PC 비교 대시보드

쿠팡에서 확인한 태블릿PC 3종을 가격 상태, 핵심 차이, 선택 이유와 함께 비교하는 정적 HTML 대시보드입니다.

## 공개 파일

- `index.html` — GitHub Pages 기본 진입 페이지
- `shopping-compare.html` — 인쇄/PDF 저장 버튼이 포함된 비교 페이지
- `autumn-background.png` — 대시보드 배경 이미지

상품 이미지 일부는 외부 이미지 주소를 사용하므로 페이지를 열 때 인터넷 연결이 필요할 수 있습니다.

## 주의

- 가격과 옵션은 변동될 수 있으므로 구매 전 쿠팡 상품 페이지에서 다시 확인하세요.
- 확인하지 못한 가격·후기·실사용 성능은 `확인 필요`로 표시했습니다.
- 이 저장소에는 비밀번호, 토큰, 인증 코드, 개인 설정 파일을 포함하지 않습니다.

## GitHub Pages 공개 전 체크리스트

1. GitHub에 로그인하고 새 저장소를 만듭니다.
2. 저장소를 공개할지 여부를 확인합니다.
3. 로컬에서 커밋한 뒤 원격 저장소에 업로드합니다.
4. GitHub 저장소의 **Settings → Pages**에서 배포 대상을 설정합니다.
